Browser GPU parity

Runs the WebGPU kernel (process_chunk_gpu) and the CPU path (process_chunk_wasm) over the same windows and compares the two results byte for byte. Any difference means this browser's shader compiler or this GPU's driver computed something wrong. Both paths run on this page's main thread, so the page can stall for a moment on each window.
